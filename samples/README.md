# Demo samples for WinPreviewPlus

Open folder in Explorer → select a file → **Alt+P**.

| Folder | What to try |
|--------|-------------|
| 01-text | Ctrl+F → `ПРОБНИК-НАЙТИ-123` |
| 02-office | docx / xlsx / xls / pptx, Ctrl+F |
| 03-pdf | PDF find `PROBNIK-NAYTI-123` |
| 04-archive | zip listing |
| 05-images | png/jpg zoom, svg (WebView2), gif |
| 06-audio | play/pause |
| 07-video | play (WebView2) |

Search marker in most text-like files: **ПРОБНИК-НАЙТИ-123** (PDF: PROBNIK-NAYTI-123).
